rp-agent概念原型

⚙ Agent 模式：修改设定 · 管理世界书 · 世界演化 · 知识管理 · 网络搜索 · 问答 展开可用工具 ▸
🎭 角色与设定
update_character(field, value) — 修改角色卡字段（name / description / personality / scenario / world / rules，rules 换行分隔多条）
set_scene(scene) — 更新当前故事场景
📖 世界书（防全知：隐藏条目角色默认不知晓）
add_worldinfo(keys, content, public?) — 添加世界书条目（keys 为触发关键词数组；public=false 设为隐藏秘密）
update_worldinfo(id, keys?, content?, enabled?, public?) — 更新条目（public=false 设为隐藏秘密）
remove_worldinfo(id) — 删除条目
reveal_worldinfo(id) — 向角色揭示隐藏信息（剧情中得知秘密时用）
conceal_worldinfo(id) — 收回已揭示的信息
🌍 世界演化（NPC 离线行动）
advance_world(note?) — 推进世界：时间前进、NPC 行动演化
query_world() — 查看世界状态（时间 / NPC / 近期事件）
set_world_time(time) — 直接设置世界时间
add_npc(name, location?, action?, goal?) — 添加或更新 NPC
update_npc(name, action?, location?, goal?) — 更新 NPC 字段
remove_npc(name) — 移除 NPC
🔎 网络
web_search(query, max_results?) — 互联网实时搜索（返回标题/链接/摘要）
web_extract(url) — 提取网页正文（Markdown，自动截断）
⚙ 系统管理（Agent 对话拥有最高权限）
get_system_config() — 查看 API 配置集 / 导演设置 / 演化策略
update_system_config(...) — 切换/修改 API 配置、导演设置、演化策略（API Key 请在设置界面填写）
提示：切换模式时同步切换对话记录；"清理对话历史"本地执行（不经过 AI）。
设置里可调节：世界演化模式（激进/平衡/保守）、演化方向、自动推演间隔、🤖 幕后 Agent 管理。
